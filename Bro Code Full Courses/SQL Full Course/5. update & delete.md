# ✏️ MySQL UPDATE & DELETE

The `UPDATE` and `DELETE` statements are used to modify and remove existing data from a table.

---

# UPDATE

### `UPDATE <table name> SET <column> = <value> WHERE <condition>`

The `UPDATE` statement changes existing values in one or more rows.

---

## Update a Single Column

Example:

```sql id="q4m8sa"
UPDATE employees
SET hourly_pay = 10.25
WHERE employee_id = 6;
```

This changes the `hourly_pay` of the employee with ID `6` to `10.25`.

You can check the result with:

```sql id="x7v2kp"
SELECT * FROM employees;
```

---

# Update Multiple Columns

You can change multiple columns in the same `UPDATE` statement.

Example:

```sql id="m9w3zt"
UPDATE employees
SET
    hourly_pay = 10.50,
    hire_date = "2023-01-07"
WHERE employee_id = 6;
```

This changes both the hourly pay and hire date of employee `6`.

---

# Set a Value to `NULL`

A column can be set to `NULL` if the column allows it.

Example:

```sql id="p2n6vb"
UPDATE employees
SET
    hourly_pay = 10.50,
    hire_date = NULL
WHERE employee_id = 6;
```

This removes the current value from `hire_date` and replaces it with `NULL`.

---

# ⚠️ Updating All Rows

If you leave out the `WHERE` clause, the update applies to **every row** in the table.

Example:

```sql id="r8k4lm"
UPDATE employees
SET
    hourly_pay = 10.50;
```

This changes the `hourly_pay` of every employee to `10.50`.

⚠️ Always check your `WHERE` condition before running an `UPDATE`.

---

# DELETE

### `DELETE FROM <table name> WHERE <condition>`

The `DELETE` statement removes rows from a table.

---

## Delete a Specific Row

Example:

```sql id="v5q1xa"
DELETE FROM employees
WHERE employee_id = 6;
```

This deletes the employee whose ID is `6`.

You can check the result with:

```sql id="n7m3wd"
SELECT * FROM employees;
```

---

# ⚠️ Delete All Rows

If you leave out the `WHERE` clause, `DELETE` removes **every row** from the table.

Example:

```sql id="c9p2zt"
DELETE FROM employees;
```

The table itself still exists, but all of its rows are removed.

You can check the table with:

```sql id="k4x8va"
SELECT * FROM employees;
```

---

# UPDATE vs DELETE

| Command  | Purpose                          |
| -------- | -------------------------------- |
| `UPDATE` | Changes existing data            |
| `DELETE` | Removes rows                     |
| `WHERE`  | Controls which rows are affected |

⚠️ The `WHERE` clause is especially important when using `UPDATE` or `DELETE`. Without it, the operation affects every row in the table.
