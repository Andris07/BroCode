# ⚙️ MySQL DEFAULT

The `DEFAULT` constraint automatically provides a value for a column when no value is specified.

This is useful when a column should have a standard value without having to provide it manually every time.

---

# Default Values

For example, products can initially have a price of `0.00`.

Example data:

```sql id="a7k2mp"
INSERT INTO products
VALUES
(104, "straw", 0.00),
(105, "napkin", 0.00),
(106, "plastic fork", 0.00),
(107, "plastic spoon", 0.00);
```

You can view the products with:

```sql id="x4m8qs"
SELECT * FROM products;
```

These rows can later be removed:

```sql id="n6p1vd"
DELETE FROM products
WHERE price = 0.00;
```

---

# Define DEFAULT When Creating a Table

You can define a default value when creating a table.

Example:

```sql id="r9w3ka"
CREATE TABLE products
(
    product_id INT,
    product_name VARCHAR(25),
    price DECIMAL(4, 2) DEFAULT 0.00
);
```

If no value is provided for `price`, MySQL automatically uses `0.00`.

You can view the table with:

```sql id="v2q7lm"
SELECT * FROM products;
```

---

# Add DEFAULT to an Existing Column

You can also add a default value to an existing column.

Example:

```sql id="m5x8zt"
ALTER TABLE products
ALTER
price
SET
DEFAULT 0;
```

The `price` column will now use `0` as its default value.

You can check the table again with:

```sql id="k3n1pa"
SELECT * FROM products;
```

---

# Insert Rows Using DEFAULT

When a column has a default value, you can simply leave that column out of the `INSERT` statement.

Example:

```sql id="q8v4ls"
INSERT INTO products
(product_id, product_name)
VALUES
(104, "straw"),
(105, "napkin"),
(106, "plastic fork"),
(107, "plastic spoon");
```

Because `price` was not specified, MySQL automatically assigns its default value.

You can view the results with:

```sql id="z1m6wd"
SELECT * FROM products;
```

The inserted products will have a `price` of `0`.

---

# DEFAULT with `NOW()`

`DEFAULT` can also be used with functions such as `NOW()`.

Example:

```sql id="f7p2xa"
CREATE TABLE transactions
(
    transaction_id INT,
    amount DECIMAL(5, 2),
    transaction_date DATETIME DEFAULT NOW()
);
```

The `transaction_date` column automatically receives the current date and time when a new row is inserted without specifying a date.

You can view the table with:

```sql id="c9w4kn"
SELECT * FROM transactions;
```

---

# Insert a Transaction

You can insert a transaction without specifying `transaction_date`.

Example:

```sql id="t5v8qm"
INSERT INTO transactions
(transaction_id, amount)
VALUES
(1, 4.99);
```

MySQL automatically fills in `transaction_date` using `NOW()`.

More transactions can be added in the same way:

```sql id="y2n6ld"
INSERT INTO transactions
(transaction_id, amount)
VALUES
(2, 2.89);
```

```sql id="p4x7sa"
INSERT INTO transactions
(transaction_id, amount)
VALUES
(3, 8.37);
```

You can view the results with:

```sql id="m8q1zt"
SELECT * FROM transactions;
```

---

# Important Notes

## `DEFAULT`

Provides an automatic value when no value is specified.

For example:

```text id="v3k9wp"
price: DEFAULT 0.00
```

If the `price` is omitted during an insert:

```text id="h6m2xa"
price → 0.00
```

The default value is only used when no value is provided for the column. It does not override a value that is explicitly inserted.
