# 🧩 MySQL SUBQUERIES

A **subquery** is a query placed inside another SQL query.

The inner query is executed as part of the outer query and its result is used by the main query.

Subqueries are useful when the result of one query is needed to answer another query.

---

# Basic SUBQUERY

A subquery is usually written inside parentheses:

```sql id="8f3k2m"
(
    SELECT ...
)
```

For example, we can first calculate the average hourly pay:

```sql id="7q5n1x"
SELECT AVG(hourly_pay)
FROM employees;
```

This returns the average `hourly_pay` of all employees.

We can then use that result inside another query.

---

# SUBQUERY in SELECT

The result of a subquery can be included as an additional column.

Example:

```sql id="m8v2kc"
SELECT
    first_name,
    last_name,
    hourly_pay,
    (SELECT AVG(hourly_pay) FROM employees) AS "avg_pay"
FROM employees;
```

The subquery:

```sql id="n4x7qa"
SELECT AVG(hourly_pay) FROM employees
```

calculates the average pay.

That value is then displayed as `avg_pay` for each employee.

The result could look like:

```text id="d6p1ws"
first_name    last_name    hourly_pay    avg_pay
Eugene        Krabs        25.50         15.31
Squidward     Tentacles    15.00         15.31
Spongebob     Squarepants  12.50         15.31
...
```

The average is calculated by the subquery and can then be used by the outer query.

---

# SUBQUERY in WHERE

A subquery can also be used inside a `WHERE` condition.

Example:

```sql id="w2r8mz"
SELECT
    first_name,
    last_name,
    hourly_pay
FROM employees
WHERE
    hourly_pay > (SELECT AVG(hourly_pay) FROM employees);
```

Here, MySQL first calculates the average hourly pay:

```text id="q6n3vb"
AVG(hourly_pay)
```

Then the outer query returns only employees whose hourly pay is **greater than the average**.

In simple terms:

```text id="x4k9pa"
1. Calculate average pay
          ↓
2. Compare each employee's pay
          ↓
3. Return employees above the average
```

This is a very useful pattern for comparing individual rows against an aggregate value.

---

# SUBQUERY with IN

A subquery can also return a list of values that can be used with `IN`.

Example:

```sql id="c7m1vx"
SELECT
    first_name,
    last_name
FROM customers
WHERE
    customer_id IN
(
    SELECT DISTINCT customer_id
    FROM transactions
    WHERE customer_id IS NOT NULL
);
```

The inner query finds the customer IDs that appear in the `transactions` table.

```sql id="j5p8qd"
SELECT DISTINCT customer_id
FROM transactions
WHERE customer_id IS NOT NULL
```

`DISTINCT` removes duplicate customer IDs.

The outer query then finds the customers whose `customer_id` is included in that list.

In other words:

> Show customers who have made at least one transaction.

---

# SUBQUERY with NOT IN

`NOT IN` does the opposite.

Example:

```sql id="v9w3kf"
SELECT
    first_name,
    last_name
FROM customers
WHERE
    customer_id NOT IN
(
    SELECT DISTINCT customer_id
    FROM transactions
    WHERE customer_id IS NOT NULL
);
```

The subquery finds customers who appear in `transactions`.

The outer query then selects customers whose IDs are **not** in that list.

In other words:

> Show customers who have not made a transaction.

The `IS NOT NULL` condition in the subquery is important because `NULL` can cause unexpected behavior when using `NOT IN`.

---

# 🧠 Outer Query vs SUBQUERY

A subquery usually has two parts:

```text id="q8m4tz"
OUTER QUERY
    ↓
Main query that produces the final result

    ↑
SUBQUERY
    ↓
Provides data used by the outer query
```

For example:

```sql id="h2x7nb"
SELECT first_name, last_name
FROM employees
WHERE hourly_pay >
(
    SELECT AVG(hourly_pay)
    FROM employees
);
```

The **subquery** calculates the average.

The **outer query** uses that average to find employees who earn more than it.

---

# 💡 Quick Summary

| Pattern               | Purpose                                |
| --------------------- | -------------------------------------- |
| `(SELECT ...)`        | Create a subquery                      |
| Subquery in `SELECT`  | Add a calculated value                 |
| Subquery in `WHERE`   | Compare against another query's result |
| `IN (SELECT ...)`     | Match values returned by a subquery    |
| `NOT IN (SELECT ...)` | Exclude values returned by a subquery  |

A subquery is essentially:

> **A query inside another query.**

They become especially useful when you need to **calculate something first and then use that result in another query**.
