# 📋 MySQL Tables

# Create a Table

### `CREATE TABLE <table name>`

Creates a new table with specified columns and data types.

Example:

```sql
CREATE TABLE employees
(
    employee_id INT,
    first_name VARCHAR(50),
    last_name VARCHAR(50),
    hourly_pay DECIMAL(5, 2),
    hire_date DATE
);
```

The table contains:

* `employee_id` — integer number
* `first_name` — text with a maximum length of 50 characters
* `last_name` — text with a maximum length of 50 characters
* `hourly_pay` — decimal number
* `hire_date` — date value

---

# View a Table

### `SELECT * FROM <table name>`

Displays all columns and rows from a table.

Example:

```sql
SELECT * FROM employees;
```

---

# Rename a Table

### `RENAME TABLE <old name> TO <new name>`

Changes the name of an existing table.

Example:

```sql
RENAME TABLE employees TO workers;
```

The table is now called `workers`.

You can rename it back:

```sql
RENAME TABLE workers TO employees;
```

---

# Delete a Table

### `DROP TABLE <table name>`

Permanently deletes a table and all of its data.

Example:

```sql
DROP TABLE employees;
```

⚠️ Be careful when using `DROP TABLE` because the table and its data will be permanently deleted.

---

# Add a Column

### `ALTER TABLE <table name> ADD <column name> <data type>`

Adds a new column to an existing table.

Example:

```sql
ALTER TABLE employees
ADD phone_number VARCHAR(15);
```

You can check the updated table with:

```sql
SELECT * FROM employees;
```

---

# Rename a Column

### `ALTER TABLE <table name> RENAME COLUMN <old name> TO <new name>`

Changes the name of an existing column.

Example:

```sql
ALTER TABLE employees
RENAME COLUMN phone_number TO email;
```

The `phone_number` column is now called `email`.

---

# Modify a Column

### `ALTER TABLE <table name> MODIFY COLUMN <column name> <data type>`

Changes the definition or data type of an existing column.

Example:

```sql
ALTER TABLE employees
MODIFY COLUMN email VARCHAR(100);
```

The `email` column can now store up to 100 characters.

---

# Change Column Position

### `ALTER TABLE <table name> MODIFY <column name> <data type> AFTER <column name>`

Moves a column to a specific position in the table.

Example:

```sql
ALTER TABLE employees
MODIFY email VARCHAR(100)
AFTER last_name;
```

This moves the `email` column directly after the `last_name` column.

### `FIRST`

Instead of `AFTER`, you can use `FIRST` to move the column to the beginning of the table.

Example:

```sql
ALTER TABLE employees
MODIFY email VARCHAR(100)
FIRST;
```

---

# Remove a Column

### `ALTER TABLE <table name> DROP COLUMN <column name>`

Permanently removes a column and all of its data from the table.

Example:

```sql
ALTER TABLE employees
DROP COLUMN email;
```

You can check the updated table with:

```sql
SELECT * FROM employees;
```

⚠️ Be careful when dropping a column because all data stored in that column will be permanently deleted.
