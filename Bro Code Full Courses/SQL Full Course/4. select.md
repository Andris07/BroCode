# 🔎 MySQL SELECT

The `SELECT` statement is used to retrieve data from a table.

It can be used to:

* 🔍 retrieve specific rows
* 📋 retrieve specific columns
* 🎯 filter results with conditions
* ⚖️ compare values
* 🧩 combine multiple conditions

---

# Select All Columns

### `SELECT * FROM <table name>`

The `*` means **all columns**.

Example:

```sql id="m4j2xa"
SELECT * FROM employees;
```

This returns every column and every row from the `employees` table.

---

# Select Specific Columns

You can specify which columns you want to retrieve.

Example:

```sql id="v8k1qp"
SELECT
    first_name,
    last_name
FROM employees;
```

Only the `first_name` and `last_name` columns are returned.

You can also change the order of the columns:

```sql id="r5n9wd"
SELECT
    last_name,
    first_name
FROM employees;
```

The order in the `SELECT` statement determines the order of the returned columns.

---

# The `WHERE` Clause

### `SELECT <columns> FROM <table> WHERE <condition>`

The `WHERE` clause filters the rows returned by a query.

Only rows that match the condition are returned.

Example:

```sql id="x2p7lm"
SELECT *
FROM employees
WHERE employee_id = 1;
```

This returns the employee whose `employee_id` is `1`.

---

# Filtering by Text

You can compare text values using `=`.

Example:

```sql id="c9w3zt"
SELECT *
FROM employees
WHERE first_name = "Spongebob";
```

This returns employees whose first name is `"Spongebob"`.

---

# Comparison Operators

Comparison operators are used to compare values in a `WHERE` condition.

| Operator | Meaning                  |
| -------- | ------------------------ |
| `=`      | Equal to                 |
| `!=`     | Not equal to             |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |

---

## Greater Than or Equal

Example:

```sql id="n6q4vb"
SELECT *
FROM employees
WHERE hourly_pay >= 15;
```

Returns employees whose hourly pay is `15` or higher.

---

## Less Than or Equal

Example:

```sql id="j8s1pk"
SELECT *
FROM employees
WHERE hire_date <= "2023-01-03";
```

Returns employees hired on or before January 3, 2023.

---

## Not Equal

Example:

```sql id="w3m7xa"
SELECT *
FROM employees
WHERE employee_id != 1;
```

Returns every employee except the employee with ID `1`.

---

# Checking for `NULL`

`NULL` represents a missing or unknown value.

You should use `IS NULL` or `IS NOT NULL` to check for `NULL` values.

## Find NULL Values

```sql id="p5v2ld"
SELECT *
FROM employees
WHERE hire_date IS NULL;
```

Returns employees whose `hire_date` has no value.

---

## Find Non-NULL Values

```sql id="q9k4zt"
SELECT *
FROM employees
WHERE hire_date IS NOT NULL;
```

Returns employees whose `hire_date` contains a value.

---

# Important Notes

## `SELECT`

Determines **what data** you want to retrieve.

```text id="x8m2qa"
SELECT first_name, last_name
```

## `FROM`

Determines **which table** the data comes from.

```text id="r3v7lp"
FROM employees
```

## `WHERE`

Determines **which rows** should be returned.

```text id="k6n1wd"
WHERE hourly_pay >= 15
```

Together:

```sql id="z4p8ms"
SELECT first_name, last_name
FROM employees
WHERE hourly_pay >= 15;
```

This means:

> Select the first and last names of employees whose hourly pay is at least 15.
