# 🔗 MySQL UNION

`UNION` is used to combine the results of multiple `SELECT` statements into a single result.

It is useful when you want to combine similar data from different tables.

For example, both the `employees` and `customers` tables contain `first_name` and `last_name`, so we can combine them into one result.

---

# UNION

### `UNION`

`UNION` combines the results of two or more `SELECT` statements and **removes duplicate rows**.

Example:

```sql
SELECT first_name, last_name FROM employees
UNION
SELECT first_name, last_name FROM customers;
```

If the same `first_name` and `last_name` combination exists in both tables, it will only appear **once** in the result.

For example:

```text
employees              customers
Spongebob Squarepants  Spongebob Squarepants
Patrick   Star         Larry     Lobster
```

With `UNION`:

```text
Spongebob Squarepants
Patrick   Star
Larry     Lobster
```

The duplicate `Spongebob Squarepants` is removed.

---

# UNION ALL

### `UNION ALL`

`UNION ALL` also combines the results of multiple `SELECT` statements, but it **keeps duplicate rows**.

Example:

```sql
SELECT first_name, last_name FROM employees
UNION ALL
SELECT first_name, last_name FROM customers;
```

If the same row appears in both tables, it will appear twice in the result.

Using the previous example:

```text
Spongebob Squarepants
Patrick   Star
Spongebob Squarepants
Larry     Lobster
```

Unlike `UNION`, `UNION ALL` does not remove duplicates.

---

# 📏 Matching Number of Columns

An important rule applies to both `UNION` and `UNION ALL`:

> The `SELECT` statements must return the **same number of columns**.

For example, this works:

```sql
SELECT first_name, last_name
FROM employees

UNION

SELECT first_name, last_name
FROM customers;
```

Both queries return **2 columns**:

```text
first_name
last_name
```

But this would not work:

```sql
SELECT first_name, last_name, job
FROM employees

UNION

SELECT first_name, last_name
FROM customers;
```

❌ The first query returns 3 columns, while the second returns 2.

The number of selected columns must match.

---

# Column Order

The columns should also correspond to each other.

For example:

```sql
SELECT first_name, last_name
FROM employees

UNION

SELECT first_name, last_name
FROM customers;
```

Here, the first column is `first_name` in both queries and the second is `last_name` in both.

Think of it as combining two lists with the same structure.

---

# 🧠 UNION vs UNION ALL

| Operator    | Combines Results | Removes Duplicates |
| ----------- | ---------------- | ------------------ |
| `UNION`     | ✅                | ✅                  |
| `UNION ALL` | ✅                | ❌                  |

Both require the `SELECT` statements to return the **same number of columns**.

---

# 💡 Quick Summary

```text
UNION
→ Combine results
→ Remove duplicates

UNION ALL
→ Combine results
→ Keep duplicates
```

For both:

```text
SELECT → same number of columns
SELECT → same number of columns
```

`UNION` is useful when you want a **unique combined result**, while `UNION ALL` is useful when you want **every row from every query**, including duplicates.
