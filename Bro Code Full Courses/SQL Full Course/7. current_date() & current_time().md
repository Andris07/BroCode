# 📅 MySQL CURRENT_DATE() & CURRENT_TIME()

MySQL provides built-in functions for getting the current date, current time, and current date and time.

These are useful when working with timestamps, registration dates, appointments, logs, and other time-related data.

---

# Test Table

For testing these functions, we can create a simple table containing different date and time data types.

Example:

```sql
CREATE TABLE test
(
    my_date DATE,
    my_time TIME,
    my_datetime DATETIME
);
```

You can view the table with:

```sql
SELECT * FROM test;
```

---

# CURRENT_DATE()

### `CURRENT_DATE()`

Returns the current date.

The result contains only the date, without the time.

Example:

```sql
INSERT INTO test
VALUES
(CURRENT_DATE(), CURRENT_TIME(), NOW());
```

For example, `CURRENT_DATE()` could return:

```text
2026-08-26
```

---

# CURRENT_TIME()

### `CURRENT_TIME()`

Returns the current time.

The result contains only the time, without the date.

Example:

```sql
INSERT INTO test
VALUES
(CURRENT_DATE(), CURRENT_TIME(), NOW());
```

For example, `CURRENT_TIME()` could return:

```text
21:30:15
```

---

# NOW()

### `NOW()`

Returns the current date **and** time.

Example:

```sql
INSERT INTO test
VALUES
(CURRENT_DATE(), CURRENT_TIME(), NOW());
```

A possible result could be:

```text
2026-08-26 21:30:15
```

---

# Adding Days to a Date

You can perform simple calculations with dates.

### Add One Day

```sql
INSERT INTO test
VALUES
(CURRENT_DATE() + 1, NULL, NULL);
```

This stores tomorrow's date.

For example:

```text
2026-08-27
```

---

# Subtracting Days from a Date

### Subtract One Day

```sql
INSERT INTO test
VALUES
(CURRENT_DATE() - 1, NULL, NULL);
```

This stores yesterday's date.

For example:

```text
2026-08-25
```

# Quick Summary

| Function         | Returns               |
| ---------------- | --------------------- |
| `CURRENT_DATE()` | Current date          |
| `CURRENT_TIME()` | Current time          |
| `NOW()`          | Current date and time |

### Date Data Types

| Data Type  | Stores        |
| ---------- | ------------- |
| `DATE`     | Date only     |
| `TIME`     | Time only     |
| `DATETIME` | Date and time |
