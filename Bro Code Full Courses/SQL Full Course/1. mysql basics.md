# 🐬 MySQL Basics

## 🗄️ What Is a Database?

A **database** is an organized collection of data that can be stored, managed, searched, and modified efficiently.

For example, a school database could contain:

* 👨‍🎓 Students
* 👨‍🏫 Teachers
* 📚 Courses
* 📝 Grades

Instead of storing everything in separate files, a database allows applications to manage large amounts of structured data efficiently.

---

# 📖 Basic Database Concepts

### 🗄️ Database

A container that stores and organizes related data.

### 📋 Table

A structure inside a database that stores data in **rows and columns**.

### 📊 Row

A single record in a table.

### 🏷️ Column

A specific type of data stored for each record.

For example, a `students` table could look like this:

| id | name      | age |
| -- | --------- | --- |
| 1  | Spongebob | 30  |
| 2  | Patrick   | 38  |
| 3  | Sandy     | 27  |

Here:

* `students` is the table
* `id`, `name`, and `age` are columns
* each student is a row

---

# 🧮 What Does SQL Mean?

**SQL** stands for **Structured Query Language**.

SQL is a language used to communicate with and manage **relational databases**.

It can be used to:

* ➕ create data
* 🔍 retrieve data
* ✏️ modify data
* 🗑️ delete data
* 🗄️ create and manage databases and tables

---

# ⚙️ How Does SQL Work?

An application sends an SQL query to the database.

The database processes the query and returns a result or performs the requested operation.

For example:

```text
Application → SQL Query → Database → Result
```

A simple SQL query could look like:

```sql
SELECT * FROM students;
```

This asks the database to return all records from the `students` table.

---

# 🆚 SQL vs NoSQL

## 🧱 SQL Databases

SQL databases are usually **relational databases**.

They store data in structured tables with predefined columns and relationships between tables.

Examples:

* 🐬 MySQL
* 🪟 Microsoft SQL Server
* 🐘 PostgreSQL
* 🔶 Oracle Database

---

## 📦 NoSQL Databases

**NoSQL** databases use different data models instead of the traditional relational table structure.

They are often designed to work well with large amounts of flexible or rapidly changing data.

For example, MongoDB stores data as documents:

```text
{
    name: "Spongebob",
    age: 30,
    gpa: 3.2
}
```

---

## ⚖️ Main Differences

| SQL                               | NoSQL                                            |
| --------------------------------- | ------------------------------------------------ |
| Relational                        | Non-relational                                   |
| Tables and rows                   | Documents, key-value pairs, graphs, etc.         |
| Usually structured schema         | More flexible schema                             |
| Uses SQL                          | Uses database-specific query methods             |
| Strong relationships between data | Often designed for flexible and distributed data |

Neither approach is universally better. The right choice depends on the application and its requirements.

# 🚀 Basic MySQL Commands

## Create a Database

### `CREATE DATABASE <database name>`

Creates a new database.

Example:

```sql
CREATE DATABASE myDB;
```

---

## Select a Database

### `USE <database name>`

Selects a database to work with.

Example:

```sql
USE myDB;
```

After selecting a database, commands will operate on that database.

---

## Delete a Database

### `DROP DATABASE <database name>`

Permanently deletes a database and everything stored inside it.

Example:

```sql
DROP DATABASE myDB;
```

⚠️ Be careful when using `DROP DATABASE` because the database and its data will be permanently deleted.

---

# 🔒 Set a Database to Read-Only

### `ALTER DATABASE <database name> READ ONLY = 1`

Makes the database read-only.

Example:

```sql
ALTER DATABASE myDB READ ONLY = 1;
```

When a database is read-only, data cannot be modified.

---

# 🔓 Disable Read-Only Mode

### `ALTER DATABASE <database name> READ ONLY = 0`

Allows the database to be modified again.

Example:

```sql
ALTER DATABASE myDB READ ONLY = 0;
```

* `1` → read-only enabled 🔒
* `0` → read-only disabled 🔓
