# ↕️ MySQL ORDER BY

`ORDER BY` is used to **sort the results** of a query based on one or more columns.

By default, MySQL sorts values in **ascending order** (`ASC`).

You can use `DESC` to sort in **descending order**.

---

# ASC — Ascending Order

### `ORDER BY <column>`

If no sort direction is specified, `ASC` is used automatically.

Example:

```sql
SELECT * FROM employees
ORDER BY last_name;
```

This sorts the employees alphabetically by `last_name`.

You can also explicitly write `ASC`:

```sql
SELECT * FROM employees
ORDER BY last_name ASC;
```

Both queries produce the same sorting.

```text
A → B → C → ... → Z
```

For numbers, ascending order means:

```text
1 → 2 → 3 → 4 → ...
```

For dates:

```text
oldest → newest
```

---

# DESC — Descending Order

### `ORDER BY <column> DESC`

`DESC` reverses the sorting order.

Example:

```sql
SELECT * FROM employees
ORDER BY last_name DESC;
```

The last names are sorted from `Z` to `A`.

```text
Z → Y → X → ... → A
```

---

# Sorting Dates

`ORDER BY` can also be used with date columns.

Example:

```sql
SELECT * FROM employees
ORDER BY hire_date;
```

This sorts employees by their `hire_date` from the oldest date to the newest.

You can reverse the order with `DESC`:

```sql
SELECT * FROM employees
ORDER BY hire_date DESC;
```

Now the newest dates appear first.

---

# Sorting Numbers

You can sort numerical columns in exactly the same way.

Example:

```sql
SELECT * FROM transactions
ORDER BY amount;
```

This sorts transactions from the smallest amount to the largest.

Using `DESC` would reverse the order:

```sql
SELECT * FROM transactions
ORDER BY amount DESC;
```

---

# Sorting by Multiple Columns

`ORDER BY` can sort by more than one column.

Example:

```sql
SELECT * FROM transactions
ORDER BY amount, customer_id;
```

MySQL first sorts by `amount`.

If multiple transactions have the same `amount`, it then uses `customer_id` to determine their order.

For example:

```text
amount    customer_id
2.89      1
2.89      3
3.38      2
4.99      1
4.99      3
```

Think of the second column as a **tie-breaker**.

---

# Different Sort Directions

Each column can have its own sorting direction.

Example:

```sql
SELECT * FROM transactions
ORDER BY amount ASC, customer_id DESC;
```

This means:

1. Sort `amount` from smallest to largest.
2. If two amounts are equal, sort their `customer_id` from largest to smallest.

For example:

```text
amount    customer_id
2.89      3
2.89      1
3.38      2
4.99      3
4.99      1
```

---

# 🧠 How ORDER BY Works

You can think of an `ORDER BY` statement as giving MySQL sorting instructions:

```text
ORDER BY
    first column → main sorting
    second column → tie-breaker
    third column → another tie-breaker
```

For example:

```sql
ORDER BY amount ASC, customer_id DESC;
```

means:

> "Sort by amount from low to high. If two amounts are equal, sort those rows by customer ID from high to low."

---

# 💡 Quick Summary

| Syntax                               | Meaning                              |
| ------------------------------------ | ------------------------------------ |
| `ORDER BY column`                    | Ascending order                      |
| `ORDER BY column ASC`                | Ascending order                      |
| `ORDER BY column DESC`               | Descending order                     |
| `ORDER BY column1, column2`          | Sort by multiple columns             |
| `ORDER BY column1 ASC, column2 DESC` | Different directions for each column |

### Sort directions

```text
ASC  → smallest → largest
       A → Z
       oldest → newest

DESC → largest → smallest
       Z → A
       newest → oldest
```

`ORDER BY` only changes the **order of the query results**. It does not permanently rearrange the rows in the table.
