# 🔐 MySQL UNIQUE

The `UNIQUE` constraint prevents duplicate values from being stored in a column.

This is useful when a value should be different for every row, such as a username, email address, or product name.

---

# Create a Table with UNIQUE

You can define a column as `UNIQUE` when creating the table.

Example:

```sql id="p7k2ma"
CREATE TABLE products
(
    product_id INT,
    product_name VARCHAR(25) UNIQUE,
    price DECIMAL(4, 2)
);
```

The `product_name` column must contain unique values.

You can view the table with:

```sql id="x3v8qd"
SELECT * FROM products;
```

---

# Add UNIQUE to an Existing Table

You can also add a `UNIQUE` constraint after the table has already been created.

Example:

```sql id="m9w4zt"
ALTER TABLE products
ADD CONSTRAINT
UNIQUE(product_name);
```

This makes sure that no two rows can have the same `product_name`.

You can check the table again with:

```sql id="f2n6lp"
SELECT * FROM products;
```

---

# Duplicate Values

If you try to insert duplicate values into a `UNIQUE` column, MySQL will reject the operation.

Example:

```sql id="v8q3ka"
INSERT INTO products
VALUES
(100, "hamburger", 3.99),
(101, "fries", 1.99),
(102, "soda", 1.00),
(103, "ice cream", 1.49),
(104, "fries", 1.75);
```

The value `"fries"` appears twice in `product_name`.

Because `product_name` is `UNIQUE`, MySQL will not allow the duplicate value.

---

# Valid Insert

If every value in the `UNIQUE` column is different, the insert succeeds.

Example:

```sql id="r5m1xa"
INSERT INTO products
VALUES
(100, "hamburger", 3.99),
(101, "fries", 1.99),
(102, "soda", 1.00),
(103, "ice cream", 1.49);
```

All `product_name` values are unique, so the rows can be inserted successfully.

You can view the inserted products with:

```sql id="n7w4pz"
SELECT * FROM products;
```

---

# Important Notes

## `UNIQUE`

A `UNIQUE` constraint ensures that a column cannot contain duplicate values.

For example:

```text id="k3v8ms"
hamburger
fries
soda
ice cream
```

✅ All values are unique.

But:

```text id="q6x2ld"
hamburger
fries
soda
fries
```

❌ `"fries"` appears twice, so the constraint is violated.

`UNIQUE` is a **constraint**, not a data type. It defines a rule that the stored data must follow.
