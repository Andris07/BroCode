# 🔢 MySQL LIMIT

`LIMIT` is used to control how many rows a query returns.

It is especially useful when you only need a small number of results instead of the entire table.

---

# Basic LIMIT

### `LIMIT <number>`

The number after `LIMIT` specifies the **maximum number of rows** to return.

Example:

```sql
SELECT * FROM customers
LIMIT 1;
```

Returns at most **1 row**.

You can increase the limit:

```sql
SELECT * FROM customers
LIMIT 2;
```

Returns at most **2 rows**.

`LIMIT` does not delete or modify any data. It only affects the query result.

---

# LIMIT with ORDER BY

`LIMIT` becomes especially useful when combined with `ORDER BY`.

For example:

```sql
SELECT * FROM customers
ORDER BY last_name
LIMIT 1;
```

First, the customers are sorted alphabetically by `last_name`.

Then, only the first row is returned.

You can reverse the sorting:

```sql
SELECT * FROM customers
ORDER BY last_name DESC
LIMIT 1;
```

This returns the customer whose last name comes **last alphabetically**.

This combination is useful for questions such as:

> "Give me the first customer alphabetically."

or:

> "Give me the last customer alphabetically."

---

# LIMIT with OFFSET

`LIMIT` can also be written with two numbers:

```sql
LIMIT <offset>, <row_count>
```

The first number specifies how many rows to **skip**.

The second number specifies how many rows to **return**.

Example:

```sql
SELECT * FROM customers
LIMIT 1, 1;
```

This means:

```text
Skip 1 row
Return 1 row
```

So the second row is returned.

---

# More OFFSET Examples

```sql
SELECT * FROM customers
LIMIT 2, 1;
```

This means:

```text
Skip 2 rows
Return 1 row
```

Therefore, the **third row** is returned.

Another example:

```sql
SELECT * FROM customers
LIMIT 10, 10;
```

This means:

```text
Skip 10 rows
Return 10 rows
```

So rows **11–20** are returned.

---

# 🧠 LIMIT Syntax

There are two common forms:

### One number

```sql
LIMIT 5;
```

> Return up to 5 rows.

### Two numbers

```sql
LIMIT 5, 10;
```

> Skip 5 rows, then return up to 10 rows.

Think of it as:

```text
LIMIT offset, count
       ↓       ↓
     skip    return
```

---

# LIMIT with ORDER BY

Combining `ORDER BY` and `LIMIT` is particularly powerful.

For example:

```sql
SELECT * FROM customers
ORDER BY last_name
LIMIT 1;
```

The operations effectively happen in this order:

```text
1. Get the customers
2. Sort them by last_name
3. Return only the first row
```

This makes it possible to find things such as the **first**, **last**, or **top N** results.

---

# 💡 Quick Summary

| Syntax                 | Meaning                                  |
| ---------------------- | ---------------------------------------- |
| `LIMIT 1`              | Return up to 1 row                       |
| `LIMIT 10`             | Return up to 10 rows                     |
| `LIMIT 1, 1`           | Skip 1 row, return 1                     |
| `LIMIT 10, 10`         | Skip 10 rows, return 10                  |
| `ORDER BY ... LIMIT 1` | Sort first, then return the first result |

### Easy way to remember

```text
LIMIT 5
→ Give me the first 5 rows

LIMIT 5, 10
→ Skip 5 rows, then give me 10
```

`LIMIT` is commonly used together with `ORDER BY` when you want a specific number of sorted results.
