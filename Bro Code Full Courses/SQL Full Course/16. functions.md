# 📊 MySQL Functions

MySQL provides built-in functions that can perform calculations and manipulate data.

These functions are especially useful when working with groups of rows and when you want to summarize or format data.

---

# COUNT()

### `COUNT(<column>)`

Counts the number of non-`NULL` values in a column.

Example:

```sql
SELECT COUNT(amount) FROM transactions;
```

This returns the number of transactions that have an `amount` value.

You can give the result a more readable name using `AS`:

```sql
SELECT COUNT(amount) AS "count"
FROM transactions;
```

`AS` creates an **alias**, which is a temporary name for the result column.

---

# MAX()

### `MAX(<column>)`

Returns the highest value in a column.

Example:

```sql
SELECT MAX(amount) AS "maximum"
FROM transactions;
```

This returns the transaction with the highest amount.

---

# MIN()

### `MIN(<column>)`

Returns the lowest value in a column.

Example:

```sql
SELECT MIN(amount) AS "minimum"
FROM transactions;
```

This returns the smallest transaction amount.

---

# AVG()

### `AVG(<column>)`

Calculates the average value of a column.

Example:

```sql
SELECT AVG(amount) AS "average"
FROM transactions;
```

This calculates the average transaction amount.

---

# SUM()

### `SUM(<column>)`

Adds together all non-`NULL` values in a column.

Example:

```sql
SELECT SUM(amount) AS "sum"
FROM transactions;
```

This returns the total amount of all transactions.

---

# CONCAT()

### `CONCAT(<value1>, <value2>, ...)`

Combines multiple values into a single text value.

This is useful when you want to combine separate columns into one result.

Example:

```sql
SELECT CONCAT(first_name, " ", last_name) AS "full_name"
FROM employees;
```

This combines the `first_name` and `last_name` columns.

For example:

```text
first_name    last_name
Spongebob     Squarepants
```

becomes:

```text
full_name
Spongebob Squarepants
```

The `" "` between the two column names adds a space between the first and last name.

---

# 🏷️ AS — Aliases

`AS` gives a column or expression a temporary name in the query result.

Example:

```sql
SELECT MAX(amount) AS "maximum"
FROM transactions;
```

Instead of displaying the result under the name `MAX(amount)`, MySQL displays it as `maximum`.

The alias does **not** rename the actual column in the database.

---

# 💡 Quick Summary

| Function   | Purpose                            |
| ---------- | ---------------------------------- |
| `COUNT()`  | Counts non-`NULL` values           |
| `MAX()`    | Finds the highest value            |
| `MIN()`    | Finds the lowest value             |
| `AVG()`    | Calculates the average             |
| `SUM()`    | Calculates the total               |
| `CONCAT()` | Combines values into text          |
| `AS`       | Gives a temporary name to a result |

These functions are particularly useful for creating **summaries and statistics** from database data.
