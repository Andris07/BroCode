# 📊 MySQL GROUP BY

`GROUP BY` is used to **group rows that have the same value** in one or more columns.

It is commonly used together with aggregate functions such as:

* `SUM()` — adds values together
* `MAX()` — finds the largest value
* `MIN()` — finds the smallest value
* `AVG()` — calculates the average
* `COUNT()` — counts values

Instead of returning every individual row, `GROUP BY` allows you to perform calculations **for each group separately**.

---

# GROUP BY with SUM

Example:

```sql
SELECT SUM(amount), order_date
FROM transactions
GROUP BY(order_date);
```

This groups the transactions by `order_date` and calculates the **total amount for each date**.

For example:

```text
order_date    SUM(amount)
2023-01-01    15.50
2023-01-02    23.75
2023-01-03    8.99
```

---

# GROUP BY with MAX

`MAX()` finds the largest value within each group.

```sql
SELECT MAX(amount), order_date
FROM transactions
GROUP BY(order_date);
```

This finds the **largest transaction amount for each date**.

---

# GROUP BY with MIN

`MIN()` finds the smallest value within each group.

```sql
SELECT MIN(amount), order_date
FROM transactions
GROUP BY(order_date);
```

This finds the **smallest transaction amount for each date**.

---

# GROUP BY with AVG

`AVG()` calculates the average value within each group.

```sql
SELECT AVG(amount), order_date
FROM transactions
GROUP BY(order_date);
```

This calculates the **average transaction amount for each date**.

---

# GROUP BY with COUNT

`COUNT()` counts the values within each group.

```sql
SELECT COUNT(amount), order_date
FROM transactions
GROUP BY(order_date);
```

This tells us **how many transactions were made on each date**.

---

# GROUP BY with Customer IDs

You can group by any column, not just dates.

For example:

```sql
SELECT COUNT(amount), customer_id
FROM transactions
GROUP BY(customer_id);
```

This counts how many transactions each customer has.

The result could look like:

```text
customer_id    COUNT(amount)
1              2
2              1
3              3
```

---

# HAVING

`HAVING` is used to **filter groups** after `GROUP BY`.

This is similar to how `WHERE` filters individual rows, but `HAVING` filters the resulting groups.

Example:

```sql
SELECT COUNT(amount), customer_id
FROM transactions
GROUP BY(customer_id)
HAVING COUNT(amount) > 1;
```

This means:

> Group transactions by customer and only show customers who have made more than one transaction.

---

# HAVING with Multiple Conditions

Multiple conditions can also be used with `HAVING`.

Example:

```sql
SELECT COUNT(amount), customer_id
FROM transactions
GROUP BY(customer_id)
HAVING COUNT(amount) > 1 AND customer_id IS NOT NULL;
```

This only returns groups where:

* 🔢 The customer has more than one transaction
* 👤 The `customer_id` is not `NULL`

This is useful because transactions without a customer ID should not be treated as belonging to a specific customer.

---

# WHERE vs HAVING

One of the most important differences to remember:

```text
WHERE
→ filters individual rows

GROUP BY
→ creates groups

HAVING
→ filters groups
```

For example:

```sql
SELECT COUNT(amount), customer_id
FROM transactions
WHERE amount > 2.00
GROUP BY(customer_id)
HAVING COUNT(amount) > 1;
```

Conceptually, MySQL processes this as:

```text
1. Filter individual transactions
          ↓
2. Group the remaining rows
          ↓
3. Count each group
          ↓
4. Filter groups using HAVING
```

---

# 🧠 Why Use GROUP BY?

Without `GROUP BY`, an aggregate function usually produces one result for the entire selected dataset.

For example:

```sql
SELECT SUM(amount)
FROM transactions;
```

This gives the **total amount of all transactions**.

With `GROUP BY`:

```sql
SELECT SUM(amount), order_date
FROM transactions
GROUP BY(order_date);
```

we get a separate total for **each date**.

So:

```text
Without GROUP BY
→ one calculation for everything

With GROUP BY
→ one calculation for each group
```

# 💡 Quick Summary

| Function   | Purpose          |
| ---------- | ---------------- |
| `SUM()`    | Total value      |
| `MAX()`    | Largest value    |
| `MIN()`    | Smallest value   |
| `AVG()`    | Average value    |
| `COUNT()`  | Number of values |
| `GROUP BY` | Creates groups   |
| `HAVING`   | Filters groups   |

### Easy way to remember

```text
WHERE
  ↓
Filter rows

GROUP BY
  ↓
Create groups

HAVING
  ↓
Filter groups
```

`GROUP BY` is especially powerful when combined with aggregate functions because it allows you to turn a large collection of individual rows into useful summaries, such as **total sales per day, average payment per customer, or number of transactions per customer**.
