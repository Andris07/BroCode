# ➕ MySQL Insert Rows

# Insert a Single Row

### `INSERT INTO <table name> VALUES (...)`

Adds a new row to a table.

Example:

```sql
INSERT INTO employees
VALUES (1, "Eugene", "Krabs", 25.50, "2023-01-02");
```

This inserts a new employee with values for every column in the table.

---

# Insert Multiple Rows

You can insert multiple rows with a single `INSERT INTO` statement.

Example:

```sql
INSERT INTO employees
VALUES
(2, "Squidward", "Tentacles", 15.00, "2023-01-03"),
(3, "Spongebob", "Squarepants", 12.50, "2023-01-04"),
(4, "Patrick", "Star", 12.50, "2023-01-05"),
(5, "Sandy", "Cheeks", 17.25, "2023-01-06");
```

This adds five employees in total to the table.

---

# View the Inserted Rows

### `SELECT * FROM <table name>`

Displays all rows and columns from the table.

Example:

```sql
SELECT * FROM employees;
```

---

# Insert Into Specific Columns

You do not always have to provide a value for every column.

You can specify which columns you want to insert data into.

Example:

```sql
INSERT INTO employees (employee_id, first_name, last_name)
VALUES
(6, "Sheldon", "Plankton");
```

Only the specified columns receive values.

The remaining columns will use their default value, which is `NULL` if no other default has been defined.

---

# Important Notes

## Column Order

When you do not specify column names, the values must follow the same order as the columns in the table.

```sql
INSERT INTO employees
VALUES (1, "Eugene", "Krabs", 25.50, "2023-01-02");
```

The values correspond to:

```text
employee_id → 1
first_name  → "Eugene"
last_name   → "Krabs"
hourly_pay  → 25.50
hire_date   → "2023-01-02"
```

When inserting into specific columns, only those columns need to be provided.
