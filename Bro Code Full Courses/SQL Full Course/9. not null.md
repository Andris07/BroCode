# 🚫 MySQL NOT NULL

The `NOT NULL` constraint prevents a column from containing `NULL` values.

This is useful when a value is required and every row must have data in that column.

---

# Create a Table with NOT NULL

You can define a column as `NOT NULL` when creating the table.

Example:

```sql id="p4m8xa"
CREATE TABLE products
(
    product_id INT,
    product_name VARCHAR(25),
    price DECIMAL(4, 2) NOT NULL
);
```

The `price` column must always contain a value.

You can view the table with:

```sql id="x7q2lm"
SELECT * FROM products;
```

---

# Add NOT NULL to an Existing Column

You can also add the `NOT NULL` constraint after the table has already been created.

Example:

```sql id="m3v9zt"
ALTER TABLE products
MODIFY
price DECIMAL(4, 2) NOT NULL;
```

This changes the `price` column so that it cannot contain `NULL`.

You can check the table again with:

```sql id="f8n1kp"
SELECT * FROM products;
```

---

# NULL Value

If you try to insert `NULL` into a `NOT NULL` column, MySQL will reject the operation.

Example:

```sql id="r5x2wa"
INSERT INTO products
VALUES
(104, "cookie", NULL);
```

The `price` column does not allow `NULL`, so the insert will fail.

---

# Zero Is Not NULL

`0` and `NULL` are two different values.

* `0` → a valid numeric value
* `NULL` → no value / unknown value

Example:

```sql id="v9m4qs"
INSERT INTO products
VALUES
(104, "cookie", 0);
```

This insert succeeds because `0` is a valid number and is **not** the same as `NULL`.

You can view the inserted product with:

```sql id="k2w7ld"
SELECT * FROM products;
```

---

# Important Notes

## `NOT NULL`

Ensures that a column always contains a value.

For example:

```text id="z6p3ma"
price: 3.99
```

✅ Valid

```text id="q1v8xt"
price: 0
```

✅ Valid

```text id="n4k2wp"
price: NULL
```

❌ Not allowed

`NOT NULL` is a **constraint**, not a data type. It defines a rule that the stored data must follow.
