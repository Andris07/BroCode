# 🔀 MySQL AND, OR & NOT

`AND`, `OR`, and `NOT` are logical operators used to combine or reverse conditions in a `WHERE` clause.

They are useful when you need more control over which rows are returned.

---

# Add a Job Column

To demonstrate these operators, we first add a `job` column to the `employees` table.

Example:

```sql
ALTER TABLE employees
ADD
COLUMN job VARCHAR(25)
AFTER hourly_pay;
```

You can view the table with:

```sql
SELECT * FROM employees;
```

---

# Add Job Information

We can then assign a job title to each employee.

For example:

```sql
UPDATE employees
SET
job = "manager"
WHERE
employee_id = 1;
```

The same idea can be used to assign different job titles to the other employees.

You can check the results with:

```sql
SELECT * FROM employees;
```

---

# AND

### `AND`

`AND` requires **all conditions** to be true.

Example:

```sql
SELECT * FROM employees
WHERE
hire_date < "2023-01-05" AND job = "cook";
```

This returns employees who:

* 📅 were hired before January 5, 2023
* 👨‍🍳 have the job `"cook"`

Both conditions must be true.

---

# OR

### `OR`

`OR` requires **at least one condition** to be true.

Example:

```sql
SELECT * FROM employees
WHERE
job = "cook" OR job = "cashier";
```

This returns employees who are either:

* 👨‍🍳 a cook
* 💰 a cashier

An employee only needs to satisfy one of the conditions.

---

# NOT

### `NOT`

`NOT` reverses a condition.

Example:

```sql
SELECT * FROM employees
WHERE
NOT job = "manager" AND NOT job = "asst. manager";
```

This returns employees whose job is **neither** `"manager"` nor `"asst. manager"`.

In simple terms:

> `NOT` means "anything except this."

---

# BETWEEN

### `BETWEEN`

`BETWEEN` checks whether a value falls within a specific range.

Example:

```sql
SELECT * FROM employees
WHERE
hire_date BETWEEN "2023-01-04" AND "2023-01-07";
```

This returns employees hired between January 4 and January 7.

⚠️ `BETWEEN` is **inclusive**, meaning the two boundary values are included.

So this includes:

```text
2023-01-04
2023-01-05
2023-01-06
2023-01-07
```

---

# IN

### `IN`

`IN` checks whether a value matches **any value in a list**.

Example:

```sql
SELECT * FROM employees
WHERE
job IN ("cook", "cashier", "janitor");
```

This returns employees whose job is either:

* 👨‍🍳 `cook`
* 💰 `cashier`
* 🧹 `janitor`

This is often cleaner than writing multiple `OR` conditions.

For example, instead of:

```sql
WHERE
job = "cook" OR job = "cashier" OR job = "janitor";
```

you can write:

```sql
WHERE
job IN ("cook", "cashier", "janitor");
```

---

# 🧠 Combining Logical Operators

These operators can be combined to create more specific filters.

For example:

```sql
WHERE
hire_date < "2023-01-05"
AND
(job = "cook" OR job = "cashier");
```

This means:

> Find employees hired before January 5 who are either cooks or cashiers.

Parentheses can be used to group conditions and make the intended logic clearer.

---

# 💡 Quick Summary

| Operator  | Purpose                                            |
| --------- | -------------------------------------------------- |
| `AND`     | All conditions must be true                        |
| `OR`      | At least one condition must be true                |
| `NOT`     | Reverses a condition                               |
| `BETWEEN` | Checks whether a value is within a range           |
| `IN`      | Checks whether a value matches something in a list |

### Easy way to remember

```text
AND → this AND this
OR  → this OR this
NOT → anything except this
```

These operators become especially useful as your `WHERE` clauses become more complex and you need to precisely control which rows are selected.
