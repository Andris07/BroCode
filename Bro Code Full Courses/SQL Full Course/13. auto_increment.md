# 🔢 MySQL AUTO_INCREMENT

`AUTO_INCREMENT` automatically generates a unique number for a column whenever a new row is inserted.

It is commonly used together with a `PRIMARY KEY` to automatically generate IDs for rows.

This means you do not have to manually provide a unique ID every time you insert a new record.

---

# Create a Table with AUTO_INCREMENT

You can add `AUTO_INCREMENT` to a primary key when creating a table.

Example:

```sql
CREATE TABLE transactions
(
    transaction_id INT PRIMARY KEY AUTO_INCREMENT,
    amount DECIMAL(5, 2)
);
```

Here, `transaction_id` will automatically receive a new number whenever a transaction is inserted.

You can view the table with:

```sql
SELECT * FROM transactions;
```

---

# Insert Rows

Because `transaction_id` is automatically generated, you only need to provide the `amount`.

Example:

```sql
INSERT INTO transactions
(amount)
VALUES
(4.99),
(2.89),
(3.38),
(4.99);
```

You can view the results with:

```sql
SELECT * FROM transactions;
```

The IDs will be generated automatically:

```text
transaction_id    amount
1                 4.99
2                 2.89
3                 3.38
4                 4.99
```

Notice that even though two transactions have the same `amount`, their `transaction_id` values are different.

---

# Change the Starting Value

You can change the next `AUTO_INCREMENT` value with `ALTER TABLE`.

Example:

```sql
ALTER TABLE transactions
AUTO_INCREMENT = 1000;
```

The next automatically generated ID will start from `1000`.

---

# Delete All Rows

You can remove all rows from the table with:

```sql
DELETE FROM transactions;
```

The table itself still exists.

After changing the `AUTO_INCREMENT` starting value, you can insert new rows again:

```sql
INSERT INTO transactions
(amount)
VALUES
(4.99),
(2.89),
(3.38),
(4.99);
```

You can view the results with:

```sql
SELECT * FROM transactions;
```

The generated IDs now start from `1000`:

```text
transaction_id    amount
1000              4.99
1001              2.89
1002              3.38
1003              4.99
```

---

# Why Use AUTO_INCREMENT?

`AUTO_INCREMENT` is especially useful for primary keys.

Without it, you would have to manually create unique IDs:

```sql
INSERT INTO transactions
VALUES
(1000, 4.99),
(1001, 2.89),
(1002, 3.38);
```

With `AUTO_INCREMENT`, you only need to provide the actual data:

```sql
INSERT INTO transactions
(amount)
VALUES
(4.99),
(2.89),
(3.38);
```

MySQL handles the IDs automatically. ⚙️

---

# 💡 Quick Summary

| Feature                          | Purpose                                 |
| -------------------------------- | --------------------------------------- |
| `AUTO_INCREMENT`                 | Automatically generates numbers         |
| `PRIMARY KEY`                    | Uniquely identifies each row            |
| `AUTO_INCREMENT` + `PRIMARY KEY` | Convenient automatic row identification |

`AUTO_INCREMENT` is commonly used for IDs because it reduces manual work and helps ensure that each new row receives a different identifier.
