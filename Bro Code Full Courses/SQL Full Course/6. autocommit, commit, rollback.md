# 🔄 MySQL AUTOCOMMIT, COMMIT & ROLLBACK

These commands are used to control how changes are saved in a database.

By default, MySQL usually uses **autocommit**, which means changes are automatically saved after each statement.

---

# Disable AUTOCOMMIT

### `SET AUTOCOMMIT = OFF;`

Turns off automatic saving of changes.

Example:

```sql
SET AUTOCOMMIT = OFF;
```

After this, changes are not permanently saved until you use `COMMIT`.

---

# COMMIT

### `COMMIT;`

Permanently saves the changes made during the current transaction.

Example:

```sql
COMMIT;
```

Once changes are committed, they cannot normally be undone with `ROLLBACK`.

---

# ROLLBACK

### `ROLLBACK;`

Undoes changes made since the last `COMMIT`.

Example:

```sql
ROLLBACK;
```

This is useful when you make a mistake and want to return to the previous committed state.

---

# Example Workflow

A simple transaction can look like this:

```sql
SET AUTOCOMMIT = OFF;

UPDATE employees
SET hourly_pay = 20.00
WHERE employee_id = 1;

ROLLBACK;
```

The update is undone because it was never committed.

You can also permanently save the change:

```sql
SET AUTOCOMMIT = OFF;

UPDATE employees
SET hourly_pay = 20.00
WHERE employee_id = 1;

COMMIT;
```

The change is now saved.

---

# Enable AUTOCOMMIT Again

### `SET AUTOCOMMIT = ON;`

Turns automatic saving back on.

Example:

```sql
SET AUTOCOMMIT = ON;
```

---

# Quick Summary

| Command                | Purpose                       |
| ---------------------- | ----------------------------- |
| `SET AUTOCOMMIT = OFF` | Disable automatic saving      |
| `COMMIT`               | Permanently save changes      |
| `ROLLBACK`             | Undo uncommitted changes      |
| `SET AUTOCOMMIT = ON`  | Enable automatic saving again |
